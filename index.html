Hyena scavenges.

A Mac cleaner for developers. It finds the builds and caches you forgot, and clears them only when you say so.

Big finds. No leaks.

We pointed Hyena at one working developer’s Mac. It found 47.84 GB of caches, logs and build leftovers, 26.6 GB of it in a single npm cache. The on-device model that explained every item sent nothing anywhere.

Sniff, review, clean

  1. About a minute

    First, Hyena measures caches, logs, Xcode data and your projects. Read-only.

  2. As long as you like

    Then you open anything, file by file, and uncheck whatever stays.

  3. Seconds

    Then every path is checked again and moved to Trash.

  4. One click

    Finally, empty Trash and the space is yours.

  • Clean Now⌘↩

    See a summary of every category, then clean. Recommended items are already checked; risky ones never are.

  • Ask Hyena⌘K

    Type “old Rust builds except work” and see exactly what that selects before anything happens.

  • What is this?

    Explains any folder: what made it, what cleaning it does, and whether it’s safe, worth a check, or worth keeping.

  • Scan Again⌘R

    Measures everything again. Each category fills in the moment it finishes.

  • Never Clean This

    Protects a folder for good. Anything that contains it is skipped too.

  • Suggestions

    Every week or month, a quiet rescan and a few ideas picked for how you work. Dismiss one and it backs off.

  • Empty Trash

    Moving to Trash frees nothing yet. This does, when you’re sure.

  • Settings⌘,

    Pick categories, project folders, reminders, and how much Hyena should learn from you.

Plus .build, .dart_tool, _build, .zig-cache, .stack-work, .terraform, .venv and more: eighteen ecosystems, each matched by the file that sits beside its leftovers. A folder that only shares a name is never touched.

It thinks on your Mac, and it never deletes a thing on its own.

On macOS 26 with Apple Intelligence, Hyena uses Foundation Models locally. Everywhere else it falls back to built-in rules, so every feature still works. No account, no analytics, no network calls when it cleans.

Fair questions

Does Hyena delete things on its own? No. It suggests, you review, and nothing goes until you press Clean. Items move to Trash unless you turn on Delete immediately.

What does it find? App caches, logs, caches inside Application Support, leftovers from removed apps, Trash, Time Machine snapshots, Xcode data, package-manager caches, and build folders in your projects.

How does it know a target folder is a Rust build? It looks for the marker beside it: Cargo.toml for target, package.json for node_modules, Package.swift for .build. Same name, no marker, no match.

Can I keep part of a folder? Yes. Expand any item, see real sizes, and uncheck files or folders. Only what’s still checked is cleaned.

Where does the AI run? On your Mac, with Apple’s Foundation Models on macOS 26 and Apple Intelligence. Without them, built-in rules take over.

Does it send my file names anywhere? No. Paths, sizes and habits stay on your Mac.

What about apps that are open? Their caches are flagged and left unchecked, so you can quit the app first.

Why does Trash need Full Disk Access? macOS protects the Trash folder. Grant access to see inside it, or let Hyena ask Finder to empty it.

Will it learn my habits? If you let it. Things you keep twice start unchecked; after three keeps it offers to protect them. One button forgets it all.

Is it safe on snapshots? Only local Time Machine snapshots are listed. Your backup disk is never touched, and macOS asks for your password first.

What does it need? macOS 14 or later. The on-device AI features need macOS 26 with Apple Intelligence.

When can I download it? Hyena is in private development. Follow the project on GitHub to hear when the first signed build ships.
