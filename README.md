# hyena-app.github.io

The website for [Hyena](https://hyena-app.github.io), a Mac cleaner for developers.

Static HTML, CSS and a little JavaScript, served by GitHub Pages. No build step.

Art direction: "Type and nothing else", dealt by [tasteskill v2](https://www.tasteskill.dev/) (seed 1808658050), with Hyena's brand palette kept.

Photographs and video are from Wikimedia Commons and are credited on the page and in `assets/credits.json`.
